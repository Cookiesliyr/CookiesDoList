<b>Task Name</b>: this what will show <br>
<b>Description</b>: for additional info, can be shown from the ?<br>
<b>Task Reset</b>: you can make this task reset on daily bases on certain time, by default the task doesn't reset<br>
<b>Task Expire Date</b>: another option, you can add an experiation data for the task, for now it will turn the task groupbox Red when time expire, nothing else.<br><br>

after you fill the Task info you can the todo list components, here we have three type of components so far: Todo, Counters and Timers

<img width="601" height="605" alt="Create Task 2" src="https://github.com/user-attachments/assets/739cad5b-1d9a-4d0b-86a3-be13c59e453d" />

<b>ToDo</b>: a simple note with check mark, to represent a todo task, can have two forms: Checkbox or button.<br>
<b>Counters</b>: a simple counter where you can count to a goal, can be either a simple button or a counter with two (up and down) buttons.<br>
<b>Timer</b>: can be either time that goes up (stop watch), or goes down (timer), and could have two forms: Label or progress bar.<br>

<b>Stop button:</b> to stop the timer with left mouse click. the right mouse click will reset the timer without stopping.<br>
<b>Play button:</b> to play\pause the timer<br>
<b>Time Label\Progress bar:</b> to show the progress<br><br><br>
